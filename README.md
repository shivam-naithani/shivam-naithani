## 🚀 Featured projects

### 🎫 CRM System
A ticketing CRM built with **Laravel 12 + React 18**, connected through Inertia.js so there's no separate API layer, no token juggling and no CORS headaches. Access is controlled by role middleware *and* policies, so permissions are checked twice. It includes SLA-based due dates, a full audit trail per ticket, and a dashboard whose cards click through to filtered ticket lists.

`Laravel` `React` `Inertia.js` `PostgreSQL` `Tailwind` `Recharts`

👉 [View repository](https://github.com/shivam-naithani/crm-system)

### 📄 Resume Analyzer *(in progress)*
Paste a resume and a job description, get an ATS-style match score. The scoring engine uses TF-IDF and cosine similarity, written in plain Java. It sits behind a Spring Boot API with JWT auth and a React front end.

`Java` `Spring Boot` `Hibernate` `React` `MySQL`

## 🧭 How I like to build
- **Security in layers.** Don't rely on one check when two are cheap.
- **Tests next to features**, not after them.
- **Boring, readable code** beats clever code that nobody can debug.
