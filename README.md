## 🚀 Featured projects

### 📄 Resume Analyzer
Upload a PDF resume and a job description, and get a match score, ranked missing keywords, a section-by-section breakdown and rule-based suggestions, with no external AI service. The analysis engine is plain Java, including a custom tokenizer that keeps terms like C++, CI/CD and Node.js whole. The Spring Boot API is secured with Spring Security and JWT, with per-user ownership enforced inside the repository queries. The schema is managed with Flyway and the whole thing is backed by 116 automated tests (JUnit 5, Mockito). Deployed with the React frontend on Vercel, the Dockerized API on Render and the database on TiDB Cloud.

`Java` `Spring Boot` `Spring Security` `JWT` `Hibernate` `Flyway` `React` `MySQL` `Docker`

👉 [View repository](https://github.com/shivam-naithani/resume-analyzer) · [Live demo](https://resume-analyzer-nine-cyan.vercel.app)

### 🎫 CRM System
A ticketing CRM built with **Laravel 12 + React 18**, connected through Inertia.js so there's no separate API layer, no token management and no CORS headaches. Access is controlled by role middleware *and* policies across 5 user roles, so permissions are checked at both the route level and the record level (for example, agents can only update tickets assigned to them). It includes SLA-based due dates, a full audit trail per ticket, and a role-aware dashboard whose cards click through to filtered ticket lists.

`Laravel` `React` `Inertia.js` `PostgreSQL` `Tailwind` `Recharts`

👉 [View repository](https://github.com/shivam-naithani/crm-system)
